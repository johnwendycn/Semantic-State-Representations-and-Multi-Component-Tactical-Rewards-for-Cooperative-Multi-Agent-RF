1. EXECUTIVE SUMMARY & OBJECTIVE
================================================================================
This protocol establishes a publishable, scientifically rigorous methodology for 
evaluating whether semantic state representations (EDMS-inspired space scoring, 
pass lanes, and reachability) paired with multi-component tactical rewards (OBV 
deltas, off-ball space generation, defensive disruption) significantly outperform 
standard raw-observation baselines trained with sparse rewards.

Goal: Demonstrate not only higher match win/goal rates, but superior tactical 
decision coherence, sample efficiency, and spatial control aligned with real-world 
coaching logic.

3.2 FORMAL DEC-POMDP MATHEMATICAL FRAMEWORK
--------------------------------------------------------------------------------
The multi-agent football simulation is modeled as a Decentralized Partially 
Observable Markov Decision Process (Dec-POMDP) defined by the tuple:

  M = < I, S, {A_i}, P, {R_i}, {Omega_i}, {O_i}, gamma >

Where:
  - I = {1, ..., N} is the finite set of controllable agents (attacking squad).
  - S in R^D is the true global environment state (positions and velocities of 
    all players, ball coordinates, ball ownership, match clock, scoreline).
  - A_i is the discrete action space for agent i (GRF action set: idle, 8-directional 
    movement, short pass, long pass, high pass, shot, sprint, tackle).
    Joint action space: A = A_1 x ... x A_N.
  - P(s' | s, a): Transition probability distribution from state s under joint action a.
  - Omega_i is the observation space for agent i.
  - O_i(s): Observation function mapping global state s to local agent observation o_i.
  - R_i(s, a, s'): Local reward signal received by agent i.
  - gamma in [0, 1): Discount factor (standard: gamma = 0.993).

Each agent selects actions according to a decentralized policy pi_{theta_i}(a_i | o_i).
During Centralized Training with Decentralized Execution (CTDE), a centralized 
critic V_phi(s) approximates the global state-value function using the true state s.

3.3 PRECISE MATHEMATICAL FORMULATIONS (SEMANTIC TACTICAL FEATURES)
--------------------------------------------------------------------------------
Let pitch coordinates be normalized to p = [x, y] in [-1, 1] x [-0.42, 0.42].
Let active ball carrier index be b = argmin_{i in I} || p_i - p_ball ||_2.
Let Opponents be D = {d_1, ..., d_M}.
Let Attacking teammates be J = {j in I : j != b}.

1. VECTOR PROJECTION PASS-LANE OCCLUSION (L_pass):
   For a pass trajectory vector v_pass = p_j - p_b connecting ball carrier b 
   to potential receiver j, the orthogonal distance of defender d to this line is:
     
     t_proj(d) = dot(p_d - p_b, v_pass) / (|| v_pass ||_2^2)
     p_closest(d) = p_b + clip(t_proj(d), 0.0, 1.0) * v_pass
     h_perp(d) = || p_d - p_closest(d) ||_2

   The interception probability density of defender d is modeled via a Gaussian 
   corridor around the pass trajectory:
     
     P_intercept(d; b, j) = exp( - (h_perp(d)^2) / (2 * sigma_d^2) ) * I(t_proj(d) in [0, 1])

   Where sigma_d = 0.05 * (1.0 + || v_d ||_2 / v_max) reflects defender dynamic reach.
   The pass lane openness metric L_pass(b, j) in [0, 1] is:
     
     L_pass(b, j) = 1.0 - max_{d in D} P_intercept(d; b, j)

2. EDMS-INSPIRED SPACE SCORE S(j):
   Quantifies spatial dominance, receiver safety, and tactical utility:
     
     S(j) = k1 * D_ball(j) + k2 * D_def(j) + k3 * L_pass(b, j)

   Calibrated Standard Parameters:
     k1 = -0.50  (Penalizes excessive distance from ball carrier)
     k2 =  0.30  (Rewards spatial separation from nearest opposing defender)
     k3 =  0.40  (Rewards open passing angle)

   Where:
     - D_ball(j) = || p_j - p_b ||_2 / D_max  (with D_max = sqrt(2^2 + 0.84^2))
     - D_def(j)  = min_{d in D} || p_j - p_d ||_2 / D_safe  (clamped to [0, 1], D_safe = 0.20)

3. TIME-TO-REACH (TTR) & PITCH CONTROL DOMINANCE:
   The physical arrival time of player k (attacking or defending) to target x:
     
     TTR(k, x) = t_react + (|| p_k - x ||_2) / (v_max)

   Pitch control probability at target location x follows a logistic transition:
     
     PC_team(x) = sigmoid( lambda_TTR * ( min_{d in D} TTR(d, x) - min_{j in I} TTR(j, x) ) )
     Where lambda_TTR = 4.0.

4. SHOT VIABILITY SCORE (xG SURROGATE):
   Let goal posts be located at g_left = [1.0, -0.044] and g_right = [1.0, 0.044].
   Subtended visual angle theta_goal(j):
     
     theta_goal(j) = arccos( dot(g_left - p_j, g_right - p_j) / (||g_left - p_j|| * ||g_right - p_j||) )

   Let goalkeeper gk have projection angle theta_gk(j) and angular width phi_gk(j).
   Shot Score evaluates unoccluded angle and distance decay:
     
     Shot_Score(j) = max(0, theta_goal(j) - phi_gk(j)) * exp( - alpha_shot * || p_goal_center - p_j ||_2 )
     Where alpha_shot = 2.5.

5. MARKOVIAN ON-BALL VALUE (OBV) & EXPECTED THREAT (xT):
   Discretize the pitch into M x N cells (16 x 12).
   Let V(u, v) satisfy the Bellman transition equation on historical event data:
     
     V(u, v) = s(u, v) * g(u, v) + (1 - s(u, v)) * sum_{u', v'} T((u', v') | (u, v)) * V(u', v')

   Where:
     - s(u, v) is shot probability from cell (u, v).
     - g(u, v) is goal conversion probability given a shot from (u, v).
     - T((u', v') | (u, v)) is transition probability of successful pass/carry to (u', v').
   
   Delta-OBV for ball progression from p_t to p_{t+1}:
     Delta_OBV(t) = V(cell(p_{t+1})) - V(cell(p_t))

3.4 COMPOSITE TACTICAL REWARD FORMULATION & POLICY INVARIANCE
--------------------------------------------------------------------------------
The per-step joint reward signal R_total(t) is defined as:

  R_total(t) = w_sparse  * r_sparse(t)
             + w_obv     * Delta_OBV(t)
             + w_space   * r_space(t)
             + w_disrupt * r_disrupt(t)

Where:
  1. r_sparse(t) in {-1.0, 0.0, +1.0} (Goal scored / conceded).
  2. Delta_OBV(t) = clip( V(cell(p_{t+1})) - V(cell(p_t)), -0.5, 0.5 ).
  3. r_space(t) = sum_{j in J} max( 0.0, S_t(j) - S_{t-1}(j) ) * I(dot(v_j, [1, 0]) > 0).
     (Rewards off-ball players generating viable space via forward/lateral runs).
  4. r_disrupt(t) = max_{d in D} || p_d(t) - p_d(t-1) ||_2 * I(is_marking(d, j)).
     (Rewards pulling man-marking defenders out of central defensive zones).

POTENTIAL-BASED REWARD SHAPING (PBRS) GUARANTEE:
  When tactical reward terms are expressed as potential differences:
    F(s_t, s_{t+1}) = gamma * Phi(s_{t+1}) - Phi(s_t)
    with Phi(s) = w_obv * V(p_ball) + w_space * sum_j S(j),
  the optimal policy pi* is mathematically guaranteed to be invariant (Ng et al., 1999),
  preventing reward-hacking loops and ensuring policy convergence to true goal optimality.

3.5 FORMAL ALGORITHMS (PSEUDOCODE)
--------------------------------------------------------------------------------

================================================================================
ALGORITHM 1: Vectorized Semantic State Feature Construction
================================================================================
Input:  Raw positions P_att in R^{N x 2}, P_def in R^{M x 2}, p_ball in R^2,
        Velocities V_att in R^{N x 2}, V_def in R^{M x 2}.
Output: Semantic feature tensor F_sem in R^{N x d_feat}.

1: b <- argmin_{i} || P_att[i] - p_ball ||_2            // Identify ball carrier
2: D_ball <- || P_att - P_att[b] ||_2 / D_max           // Distance to ball carrier [N]
3: Dist_matrix <- cdist(P_att, P_def)                   // Pairwise Euclidean [N x M]
4: D_def <- min_{cols}(Dist_matrix) / D_safe            // Nearest defender distance [N]
5:
6: // Vectorized Pass-Lane Occlusion Calculation:
7: V_pass <- P_att - P_att[b]                           // Passing vectors [N x 2]
8: Norm_sq <- sum(V_pass^2, axis=1, keepdims=True) + 1e-6
9: Diff_def <- P_def[:, None, :] - P_att[b]             // [M x 1 x 2]
10: Proj <- sum(Diff_def * V_pass, axis=2) / Norm_sq    // Projections [M x N]
11: Proj_clamped <- clip(Proj, 0.0, 1.0)
12: Closest_pt <- P_att[b] + Proj_clamped[:, :, None] * V_pass
13: H_perp <- || P_def[:, :, None] - Closest_pt ||_2    // Orthogonal distance [M x N]
14: P_intercept <- exp(- (H_perp^2) / (2 * sigma_d^2)) * (Proj >= 0) * (Proj <= 1)
15: L_pass <- 1.0 - max_{rows}(P_intercept)             // Pass openness [N]
16:
17: // Compute Space Score:
18: Space_Score <- k1 * D_ball + k2 * D_def + k3 * L_pass
19:
20: // Compute Time-To-Reach (TTR) to critical zones and Shot Score:
21: TTR_att <- t_react + || P_att - P_goal ||_2 / v_max
22: Shot_Score <- ComputeShotViability(P_att, P_def[0]) // GK is P_def[0]
23:
24: F_sem <- Stack([Space_Score, D_def, L_pass, TTR_att, Shot_Score], axis=-1)
25: return F_sem

================================================================================
ALGORITHM 2: Multi-Component Tactical Reward Engine
================================================================================
Input:  State s_t, joint action a_t, next state s_{t+1}, precomputed grid V_xT.
Output: Scalar reward r_total.

1: r_sparse <- 0.0
2: if goal_scored(s_{t+1}) then r_sparse <- +1.0
3: else if goal_conceded(s_{t+1}) then r_sparse <- -1.0
4:
5: // Compute OBV progression:
6: cell_t <- DiscretizePitch(s_t.ball_pos)
7: cell_next <- DiscretizePitch(s_{t+1}.ball_pos)
8: delta_obv <- clip(V_xT[cell_next] - V_xT[cell_t], -0.5, 0.5)
9:
10: // Compute Off-Ball Space Creation:
11: S_t <- ExtractSpaceScores(s_t)
12: S_{t+1} <- ExtractSpaceScores(s_{t+1})
13: delta_space <- sum_{j != b} max(0.0, S_{t+1}[j] - S_t[j])
14:
15: // Compute Defensive Disruption:
16: disp_def <- || s_{t+1}.def_positions - s_t.def_positions ||_2
17: r_disrupt <- mean(disp_def)
18:
19: r_total <- w_sparse * r_sparse + w_obv * delta_obv + w_space * delta_space + w_disrupt * r_disrupt
20: return r_total

================================================================================
ALGORITHM 3: MAPPO Optimization Loop with Tactical State & Reward
================================================================================
Input:  Environment envs (K parallel instances), policy pi_theta, centralized critic V_phi.
Hyperparameters: Steps T = 512, Epochs E = 4, Batch B = 64, lr = 3e-4, eps = 0.2.

1: Initialize policy weights theta, critic weights phi
2: for iteration = 1 to Total_Iterations do
3:    Reset trajectory buffer D <- empty
4:    for step = 1 to T do
5:       for k = 1 to K parallel workers do
6:          o_raw, s_global <- envs[k].get_state()
7:          F_sem <- Algorithm1(s_global)                 // Extract semantic tensor
8:          o_aug <- Concatenate([o_raw, F_sem])          // Augmented local observation
9:          a_t, logp_t <- Sample(pi_theta( . | o_aug ))
10:         v_t <- V_phi(s_global)                        // Centralized state-value
11:         s_next, raw_rew, done <- envs[k].step(a_t)
12:         r_tactical <- Algorithm2(s_global, a_t, s_next)
13:         Store in buffer D: (o_aug, s_global, a_t, r_tactical, logp_t, v_t, done)
14:      end for
15:   end for
16:
17:   // Generalized Advantage Estimation (GAE):
18:   Compute delta_t^V = r_tactical + gamma * V_phi(s_{t+1}) * (1 - done) - V_phi(s_t)
19:   Compute Advantages A_t = sum_{l=0}^{T-t} (gamma * lambda)^l * delta_{t+l}^V
20:   Compute Value Targets R_target_t = A_t + V_phi(s_t)
21:   Normalize advantages: A_hat_t <- (A_t - mean(A)) / (std(A) + 1e-8)
22:
23:   // PPO Policy & Critic Update Epochs:
24:   for epoch = 1 to E do
25:      for minibatch in SampleMinibatches(D, size=B) do
26:         ratio_t <- exp( logpi_theta(a_t | o_aug) - logp_old_t )
27:         surr1 <- ratio_t * A_hat_t
28:         surr2 <- clip(ratio_t, 1.0 - eps, 1.0 + eps) * A_hat_t
29:         Loss_policy <- - mean( min(surr1, surr2) )
30:
31:         // Value Loss with Clipping:
32:         v_pred <- V_phi(s_global)
33:         v_clipped <- v_old + clip(v_pred - v_old, -eps, eps)
34:         Loss_value <- 0.5 * mean( max((v_pred - R_target)^2, (v_clipped - R_target)^2) )
35:
36:         Loss_entropy <- - mean( Entropy(pi_theta( . | o_aug)) )
37:         Total_Loss <- Loss_policy + c1 * Loss_value - c2 * Loss_entropy
38:
39:         theta <- theta - lr * grad_theta(Total_Loss)
40:         phi   <- phi   - lr * grad_phi(Total_Loss)
41:      end for
42:   end for
43: end for

3.6 COMPUTATIONAL TIME & SPACE COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------

[A] SEMANTIC FEATURE ENGINE (PER ENVIRONMENT STEP):
  Let N = number of attacking agents (e.g., N = 3 for Academy 3v1; N = 10 outfield for 11v11).
  Let M = number of opposing defenders (e.g., M = 2 for Academy 3v1; M = 11 for 11v11).

  1. Distance & Spatial Metrics:
     - Distance to ball: O(N) operations.
     - Pairwise defender distance matrix: O(N * M) operations.
  2. Pass-Lane Occlusion (L_pass):
     - Ray-segment projection of M defenders across N potential passing lines:
       O(N * M) arithmetic floating-point operations (FLOPs).
  3. Shot Score & TTR:
     - Angular trigonometry and exponential decay: O(N) operations.
  4. OBV / xT Grid Valuation:
     - Quantized 2D grid index lookup: O(1) time.

  TOTAL STEP TIME COMPLEXITY:
    T_step = O(N * M)
    - Academy 3v1 Scenario: N = 3, M = 2  => 6 vector checks (< 0.02 ms per step).
    - Full 11v11 Match:     N = 10, M = 11 => 110 vector checks (< 0.15 ms in NumPy).
    *Conclusion: Feature computation adds < 3% latency to simulation physics.*

  SPACE COMPLEXITY (PER STEP):
    - Semantic feature storage per agent: d_feat = 5 scalars.
    - Global feature footprint per step: O(N * d_feat) = 50 floats (~200 bytes).

[B] NEURAL NETWORK INFERENCE & TRAINING (MAPPO):
  Let D_obs be observation dimension, D_state be global state dimension, 
  and H be hidden layer dimension (standard MLP: 2 layers of H = 128 or 256).

  1. Decentralized Actor Forward Pass:
     - FLOPs per agent per step: O(D_obs * H + H^2 + H * |A|)
     - For N agents across K parallel envs: O(K * N * (D_obs * H + H^2)).
  2. Centralized Critic Forward Pass:
     - Evaluates single global state s: O(K * (D_state * H + H^2 + H)).
  3. Backward Pass & Gradient Update (Per Epoch):
     - Forward-backward compute: O( (K * T / B) * (FLOPs_actor + FLOPs_critic) )
     - With K = 16, T = 512, B = 64: 128 minibatches per epoch.
  
  PEAK MEMORY / SPACE COMPLEXITY:
    - Trajectory Rollout Buffer:
      Memory = O( K * T * [ N * D_obs + D_state + N * |A| + 2 ] )
      For K=16, T=512, N=3, D_obs=48:
      Memory footprint ~= 16 * 512 * (3 * 48 + 128 + 3 * 19) * 4 bytes ~= 10.8 MB.
      *Conclusion: Easily fits within standard GPU L2 cache and VRAM (requires < 1 GB VRAM).*

4.2 STATISTICAL PROTOCOL
--------------------------------------------------------------------------------
- Random Seeds: Run a minimum of 5 independent seeds (e.g., seeds 42, 101, 2024, 7, 888) 
  for every configuration.
- Uncertainty Reporting: Report Mean +/- 1 Standard Deviation and shaded 95% 
  Confidence Interval bands on training curves.
- Statistical Significance: Perform two-tailed Welches t-test or Wilcoxon 
  signed-rank test (p < 0.05) and report Cohen's d effect sizes.

     - Evaluate agent policy when Leading vs. Level vs. Trailing.

       and increases it when trailing (>=35%).

     - Measure time steps elapsed between possession loss and reorganization 
       into defensive rest-defense shape.
  3. Visual Trajectory Heatmaps:
     - Generate pitch-control heatmaps and Voronoi tessellations comparing 
     - Baseline vs. Treatment runs.
