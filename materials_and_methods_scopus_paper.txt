3.1 EXPERIMENTAL TESTBED AND DATA SOURCES (MATERIALS)
--------------------------------------------------------------------------------
3.1.1 Google Research Football Simulation Environment
The primary experimental simulation platform utilized in this study is Google 
Research Football (GRF) v2.8 (Kurach et al., 2020), an open-source, physics-driven 
association football simulator built upon the open-source football engine of 
Gameplay Football. GRF simulates realistic player dynamics, non-linear ball 
aerodynamics, collision physics, and official match rules (including offside, 
fouls, and corner kicks) at 10 Hz physical integration steps.

To evaluate cooperative multi-agent dynamics under controlled, reproducible conditions, 
we configure three benchmark scenarios representing progressive tactical complexity:
  1. Academy 3 vs. 1 with Goalkeeper (`academy_3_vs_1_with_keeper`): Isolates 
     overload creation, spatial spacing, passing lane geometry, and triangular 
     support under defensive pressure.
  2. Academy Run, Pass, and Shoot with Goalkeeper (`academy_run_pass_and_shoot_with_keeper`): 
     Evaluates high-tempo diagonal off-ball penetration runs and final execution.
  3. Full Match 11 vs. 11 Stochastic (`11_vs_11_easy_stochastic_v2`): Evaluates full-squad 
     collective tactical phase transitions between build-up, progression, and 
     rest-defense against the built-in rule-based AI opponent.

3.1.2 StatsBomb Open Event and Tracking Dataset
To calibrate tactical valuation metrics and real-world spatial distributions without 
relying on black-box commercial tools, we employ the publicly accessible StatsBomb 
Open Event Dataset (StatsBomb, 2023), comprising granular spatio-temporal event 
data across more than 140 competitions (over 3,000 professional matches). Each 
match record contains exact (x, y) pitch coordinates, timestamps, player identifiers, 
action types, and pass outcomes. The event coordinates are standardized onto the 
continuous Cartesian coordinate system [-1.0, 1.0] x [-0.42, 0.42] matching GRF 
conventions to pre-train and calibrate the empirical Expected Threat / On-Ball 
Value transition matrix.

3.1.3 Computing Hardware and Software Infrastructure
All training and evaluation pipelines were executed on dedicated compute instances 
comprising:
  - Processor: AMD Ryzen 9 5950X (16 physical cores, 32 threads @ 3.4 GHz).
  - Memory: 64 GB DDR4-3600 RAM.
  - Accelerator: NVIDIA GeForce RTX 3080 (10 GB GDDR6X VRAM, CUDA Core Compute 8.6).
  - Operating Environment: Ubuntu 22.04.4 LTS under WSL2, Python 3.10.12, 
    PyTorch 2.1.2+cu121, Gymnasium 0.29.1, and Google Research Football 2.8.
Parallel rollouts were collected using vectorized SubprocVecEnv instances across 
16 asynchronous simulation workers per seed.

3.2 MATHEMATICAL PROBLEM FORMULATION (METHODS)
--------------------------------------------------------------------------------
3.2.1 Decentralized Partially Observable Markov Decision Process (Dec-POMDP)
The multi-player football coordination task is formalized as a Decentralized 
Partially Observable Markov Decision Process (Dec-POMDP) characterized by the tuple:

  M = < I, S, {A_i}_{i in I}, P, {R_i}_{i in I}, {Omega_i}_{i in I}, {O_i}_{i in I}, gamma >

Where:
  - I = {1, 2, ..., N} denotes the set of N controllable outfield attacking agents.
  - S subset R^D denotes the true environmental state space containing continuous 
    positions and velocities of all 22 outfield players and the ball, pitch bounds, 
    match time, and current scoreline.
  - A_i represents the discrete action space for each individual agent i in I.
  - P(s' | s, a): S x A x S -> [0, 1] represents the transition probability 
    density from global state s to s' conditioned on joint action a in A = Prod_{i in I} A_i.
  - R_i(s, a, s'): S x A x S -> R is the real-valued reward signal received by agent i.
  - Omega_i is the observation space accessible to agent i.
  - O_i(s): S -> Omega_i defines the observation function emitting local observation o_i.
  - gamma in [0, 1) is the infinite-horizon temporal discount factor (set to gamma = 0.993).

3.2.2 Observation and Joint Action Spaces
  - Action Space A_i: Each controllable agent commands a discrete 19-dimensional 
    action space native to GRF: {0: Idle, 1-8: Eight-directional locomotion, 9: Short 
    pass, 10: Long pass, 11: High pass, 12: Shot, 13: Deflect, 14: Sliding tackle, 
    15: Dribble start, 16: Dribble stop, 17: Sprint, 18: Release direction}.
  - Baseline Observation Space (Control): Vector o_i^{raw} in R^{115} encoding raw 
    Cartesian positions and velocity vectors of teammate outfield players, opponents, 
    ball coordinates, ball possession ownership, and match context flags.
  - Novel Semantic Observation Space (Treatment): Augmented observation vector:
      o_i^{aug} = [ o_i^{raw}, F_i^{sem} ] in R^{115 + d_feat}
    where F_i^{sem} encodes domain-informed tactical representations formulated in Section 3.3.

3.3 SEMANTIC FEATURE ENGINEERING PIPELINE
--------------------------------------------------------------------------------
Let p_k = [x_k, y_k]^T in [-1.0, 1.0] x [-0.42, 0.42] denote the Cartesian 2D position 
of player k on the normalized pitch. Let b = argmin_{i in I} || p_i - p_{ball} ||_2 
designate the active ball-carrier index. Let D = {d_1, ..., d_M} denote the set of 
M opposing outfield defenders, and let J = {j in I : j != b} denote off-ball teammates.

3.3.1 Vectorized Dynamic Pass-Lane Occlusion Model (L_pass)
For each prospective receiver j in J, the linear pass trajectory connecting the 
ball-carrier to teammate j is defined by the vector v_{pass} = p_j - p_b. The scalar 
projection t_{proj}(d) of defender d in D along this passing vector is computed as:

  t_{proj}(d) = < p_d - p_b, v_{pass} > / ( || v_{pass} ||_2^2 + epsilon )

The closest point on the line segment connecting p_b and p_j to defender d is:

  p_{closest}(d) = p_b + clip(t_{proj}(d), 0.0, 1.0) * v_{pass}

The orthogonal Euclidean deviation h_{perp}(d) is given by:

  h_{perp}(d) = || p_d - p_{closest}(d) ||_2

The dynamic interception probability density of defender d is modeled via a Gaussian 
corridor whose standard deviation scales with the defender's instantaneous velocity v_d:

  P_{intercept}(d; b, j) = exp( - (h_{perp}(d)^2) / (2 * sigma_d^2) ) * I( t_{proj}(d) in [0, 1] )
  sigma_d = sigma_0 * ( 1.0 + || v_d ||_2 / v_{max} )

Where sigma_0 = 0.05 and v_{max} = 1.0. The net pass-lane availability metric 
L_{pass}(b, j) in [0, 1] is:

  L_{pass}(b, j) = 1.0 - max_{d in D} P_{intercept}(d; b, j)

3.3.2 Calibrated Dynamic Space Score Formulation (EDMS-Derived)
The spatial viability and receiver readiness of off-ball teammate j is quantified 
via the Space Score S(j):

  S(j) = k_1 * D_{ball}(j) + k_2 * D_{def}(j) + k_3 * L_{pass}(b, j)

Where:
  - D_{ball}(j) = || p_j - p_b ||_2 / D_{max}  (Normalized Euclidean distance; D_{max} = 2.17).
  - D_{def}(j)  = min_{d in D} || p_j - p_d ||_2 / D_{safe} (Clamped to [0.0, 1.0]; D_{safe} = 0.20).
  - Weights are calibrated following tactical coaching literature:
      k_1 = -0.50  (Penalizes receiver disconnection / extreme distance from carrier)
      k_2 =  0.30  (Rewards defensive separation from primary marking opponent)
      k_3 =  0.40  (Rewards unblocked passing line-of-sight)

corridor is depicted in Fig. 2.

3.3.3 Time-to-Reach (TTR) and Pitch Control Dominance
The deterministic physical arrival time of any player k to arbitrary target location x 
is formalized under the Spearman potential motion model:

  TTR(k, x) = t_{react} + ( || p_k - x ||_2 ) / v_{max}

Where t_{react} = 0.15 s represents player reaction latency. Pitch control dominance 
at location x is modeled via a logistic probability distribution over the differential 
arrival time between defending and attacking teams:

  PC_{team}(x) = 1 / ( 1 + exp( - lambda_{TTR} * ( min_{d in D} TTR(d, x) - min_{j in I} TTR(j, x) ) ) )
  lambda_{TTR} = 4.0

3.3.4 Geometric Shot Viability Formulation (Surrogate xG)
Let goalposts be situated at Cartesian coordinates g_1 = [1.0, -0.044]^T and 
g_2 = [1.0, 0.044]^T. The subtended horizontal angle theta_{goal}(j) viewed from 
candidate position p_j is:

  theta_{goal}(j) = arccos( < g_1 - p_j, g_2 - p_j > / ( || g_1 - p_j ||_2 * || g_2 - p_j ||_2 ) )

Accounting for goalkeeper occlusion width phi_{gk}(j) and distance attenuation:

  Shot\_Score(j) = max(0, theta_{goal}(j) - phi_{gk}(j)) * exp( - alpha_{shot} * || p_{goal} - p_j ||_2 )
  alpha_{shot} = 2.50

3.4 TACTICAL REWARD SHAPING AND MARKOVIAN VALUATION
--------------------------------------------------------------------------------
3.4.1 Empirical Expected Threat (xT) / On-Ball Value (OBV) Grid Estimation
To assign an objective valuation to non-scoring ball movements, the pitch is 
discretized into a uniform grid of M_x x M_y = 16 x 12 cells (192 zones). 
Following the Markovian possession framework of Karunasinghe (2022), each grid cell 
(u, v) satisfies the recursive Bellman expectation equation:

  V(u, v) = s(u, v) * g(u, v) + ( 1 - s(u, v) ) * sum_{u'=1}^{16} sum_{v'=1}^{12} T( (u', v') | (u, v) ) * V(u', v')

Where s(u, v) is shot frequency from cell (u, v), g(u, v) is goal conversion probability 
conditioned on shot execution, and T( (u', v') | (u, v) ) is empirical transition probability 
matrix estimated across 1.2 million passing and carrying events from the StatsBomb corpus. 
The on-ball value transition delta induced by moving the ball from p_t to p_{t+1} is:

  Delta\_OBV(t) = clip( V( cell(p_{t+1}) ) - V( cell(p_t) ), -0.50, 0.50 )

3.4.2 Multi-Component Tactical Composite Reward Formulation
The composite step reward R_{total}(t) provided to the reinforcement learning agent is:

  R_{total}(t) = w_{sp} * r_{sp}(t) + w_{obv} * Delta\_OBV(t) + w_{space} * r_{space}(t) + w_{dis} * r_{dis}(t)

Where:
  1. r_{sp}(t) in { -1.0, 0.0, +1.0 } represents sparse outcome rewards (+1.0 for goal, -1.0 for conceded).
  2. Delta\_OBV(t) quantifies possession threat progression.
  3. r_{space}(t) = sum_{j in J} max( 0.0, S_t(j) - S_{t-1}(j) ) * I( < v_j, [1, 0]^T > > 0 )
     incentivizes forward and lateral penetrating runs that open viable passing space.
  4. r_{dis}(t) = (1 / M) * sum_{d in D} || p_d(t) - p_d(t-1) ||_2 * I( is\_marking(d, j) )
     rewards off-ball movement that draws opposing defenders away from central defensive corridors.
  
Standardized Normalized Weight Coefficients:
  w_{sp} = 1.00,  w_{obv} = 0.20,  w_{space} = 0.15,  w_{dis} = 0.10.

3.4.3 Policy Invariance Guarantee via Potential-Based Reward Shaping (PBRS)
To prevent unintended policy divergence or reward-hacking loops (e.g., perpetual 
cyclic running to collect space bonuses), the tactical shaping terms satisfy 
Potential-Based Reward Shaping (Ng et al., 1999):

  F(s_t, s_{t+1}) = gamma * Phi(s_{t+1}) - Phi(s_t)
  Phi(s) = w_{obv} * V(p_{ball}) + w_{space} * sum_{j in J} S(j)

Theorem 1 (Ng et al., 1999): Under potential-based shaping F(s, s'), any optimal 
policy pi* in the shaped Dec-POMDP M' is identical to the optimal policy in the 
original unshaped Dec-POMDP M:
  argmax_{pi} E_{M'}[ sum gamma^t R_{total}(t) ] == argmax_{pi} E_{M}[ sum gamma^t r_{sp}(t) ].

3.5 MARL ARCHITECTURE AND OPTIMIZATION PROTOCOL
--------------------------------------------------------------------------------
3.5.1 Centralized Training with Decentralized Execution (CTDE)
We implement Multi-Agent Proximal Policy Optimization (MAPPO) operating under the 
CTDE paradigm (Yu et al., 2022). Each agent i evaluates actions using only its private 
augmented observation o_i^{aug} through decentralized actor network pi_theta(a_i | o_i^{aug}). 
Conversely, a centralized critic V_phi(s) approximates global state-value during 
training using complete environmental state vector s in R^D, resolving partial 
observability and mitigating non-stationarity across agents.

3.5.2 Multi-Agent Proximal Policy Optimization (MAPPO) Objective
The actor parameters theta are optimized via the clipped surrogate objective:

  L^{CLIP}(theta) = E_{t, i} [ min( r_{t, i}(theta) * A_{t, i}^{GAE}, 
                                    clip(r_{t, i}(theta), 1 - eps, 1 + eps) * A_{t, i}^{GAE} ) ]

Where probability ratio r_{t, i}(theta) = pi_theta(a_{t, i} | o_{t, i}^{aug}) / pi_{theta_{old}}(a_{t, i} | o_{t, i}^{aug}), 
and eps = 0.20 is the clipping parameter.

The centralized critic parameters phi are optimized via the value loss:

  L^{VAL}(phi) = 0.5 * E_{t} [ max( ( V_phi(s_t) - R_t^{targ} )^2, 
                                    ( V_{phi_{old}}(s_t) + clip(V_phi(s_t) - V_{phi_{old}}(s_t), -eps, eps) - R_t^{targ} )^2 ) ]

The total training objective minimized via Adam optimizer is:

  L(theta, phi) = - L^{CLIP}(theta) + c_1 * L^{VAL}(phi) - c_2 * E_{t, i} [ H(pi_theta( . | o_{t, i}^{aug})) ]

Where c_1 = 0.50, c_2 = 0.01 is the policy entropy regularization coefficient, and H is policy entropy.

3.5.3 Generalized Advantage Estimation and Neural Network Architectures
Advantage estimates A_{t, i}^{GAE} are computed via Generalized Advantage Estimation (GAE):

  delta_t^V = R_{total}(t) + gamma * V_phi(s_{t+1}) * ( 1 - done_t ) - V_phi(s_t)
  A_t^{GAE(gamma, lambda)} = sum_{l=0}^{T - t - 1} ( gamma * lambda )^l * delta_{t+l}^V
  Where lambda = 0.95.

Network Backbones:
  - Decentralized Actor pi_theta: 3-layer Multi-Layer Perceptron (MLP) with layer 
    dimensions [Input_Dim -> 256 -> 256 -> 19 (Softmax)], utilizing Orthogonal 
    Initialization and Tanh activations.
  - Centralized Critic V_phi: 3-layer MLP with dimensions [Global_State_Dim -> 256 -> 256 -> 1 (Linear)].
Parameter capacities are maintained strictly identical across baseline and treatment conditions.

To isolate the exact causal contributors of learned agent performance, we conduct 
a controlled comparative evaluation where all environmental stochasticity, simulator 
dynamics, neural network layer configurations, optimizer hyperparameters, and total 
environment step budgets are held invariant.

3.6.3 Statistical Validation and Significance Protocol
To prevent reporting artifacts from stochastic initialization:
  1. Multi-Seed Runs: Every configuration is trained over 5 independent random seeds 
     (Seeds: 42, 101, 2024, 7, 888).
  2. Evaluation Horizon: Model weights are frozen at training completion and evaluated 
     across 1,000 continuous test matches per seed against standard GRF rule-based agents.
  3. Significance Testing: We report Mean +/- 1 Standard Deviation. Statistical 
     significance is evaluated via two-tailed Welch's unequal variances t-test 
     (alpha = 0.01) accompanied by Cohen's d effect size metric:
       d = ( mu_1 - mu_2 ) / sqrt( ( s_1^2 + s_2^2 ) / 2 )
     where d > 0.8 represents large effect size, and d > 1.2 denotes very large effect.

--------------------------------------------------------------------------------
3.7 EVALUATION METRICS AND TACTICAL BENCHMARKS
--------------------------------------------------------------------------------
To satisfy Scopus-indexed publication benchmarks, performance is evaluated along 
five quantitative axes:

1. Primary Task Performance:
   - Win Rate (%) and Net Goal Differential per 100 matches.
   - Sample Efficiency: Total environment interactions required to surpass 80% asymptotic return.

2. Tactical Phase Classification Accuracy (TPCA):
   - F1-score of agent policy representations matching ground-truth tactical phases 
     (Build-up, High Penetration, Rest-Defense) annotated by heuristic pitch rules. 
     (Published literature benchmark: > 89.0%, TACT-RLNet standard).

3. Off-Ball Movement Quality (OBMQ):
   - Average normalized space creation generated by off-ball players during active possessions:
       OBMQ = (1 / T) * sum_{t=1}^T [ S_t(off\_ball) / max(S) ]
     (Published literature benchmark: 0.85 - 0.92).

4. Decision Coherence (Cohen's kappa):
   - Inter-rater agreement metric kappa between agent passing target selections and expert 
     coaching heuristics (selecting target receiver maximizing S(j)):
       kappa = ( P_o - P_e ) / ( 1 - P_e )
     (Target threshold: kappa >= 0.70, GIRL-GNN standard).

5. Game-Contextual Risk Modulation (GIRL-GNN Protocol):
   - Measured frequency of high-risk penetrating through-balls conditioned on match scoreline:
     * Condition A (Trailing by >= 1 goal): Risk escalation target: 30% - 40%.
     * Condition B (Leading by >= 1 goal): Possession preservation target: <= 18%.
